# 인계: 전기의 숲 → 공용 엔진 분리 (1차 작업)

목표는 **「놀러오세요 전기의 숲」 한 파일에 섞여 있는 엔진과 콘텐츠를 갈라서, 다음 섬을 콘텐츠만 써서 만들 수 있게 하는 것**이다.
새 게임을 만드는 작업이 아니다. **기존 코드를 옮기는 작업**이고, 옮기다가 동작이 달라지면 실패다.

## 입력

- 원본: `_ref-electricity/sparkle-island/index.html` — 단일 HTML, **216,320 바이트 · 1,268줄 · 전부 CRLF · 축약(minify) 코드라 한 줄이 최대 10KB**.
  같이 있는 것: `lib/three.min.js`(596KB) · `art/*.png`(7장, 13MB) · `audio/maple-piano-bgm.mp3`(**86MB — 복사 금지**).
- 배포본(동작 확인용): https://scienceisjo.github.io/electricity/sparkle-island/

## 1단계 — 기계적 분리 (먼저 이것만, 코드 수정 없이)

1. 위 `<script>` 경계에서 **원본 문자열을 그대로 잘라** 파일로 뺀다. 이름은 역할대로:
   `engine/three-loader.txt`(태그 자체) · `engine/world.js` · `engine/ime.js` · `engine/audio.js` · `engine/comfort.js` · `engine/fx.js` · `engine/visit-count.js` · `engine/main.js`,
   전기 섬 것은 `islands/sparkle/model.js` · `circuit.js` · `missions.js` · `play.js` · `concept.js` 로.
   **한 글자도 고치지 않는다. 줄바꿈(CRLF)·공백·주석 그대로.**
2. `build.py` 를 만든다: 뼈대 HTML + 조각들을 **원래 순서로 다시 끼워 넣어** `index.html` 을 만든다.
3. **합격 기준: 만들어진 파일이 원본과 바이트 단위로 같아야 한다.**
   ```
   python build.py --island sparkle --out _verify/index.html
   python -c "import hashlib;p=lambda f:hashlib.sha256(open(f,'rb').read()).hexdigest();print(p('_verify/index.html'));print(p('../_ref-electricity/sparkle-island/index.html'))"
   ```
   두 해시가 다르면 1단계 미완이다. 고치지 말고 **어디가 왜 다른지** 보고할 것.
4. 여기까지 커밋하고 **멈춰서 보고한다.** 2단계는 보고 뒤에 시작한다.

## 2단계 — 섬 인터페이스 뽑기 (1단계 통과 후)

「혼합」으로 표시한 블록 2·3·10·12 에서 전기 섬에만 해당하는 값을 데이터로 꺼내, 엔진이 **섬 하나를 매니페스트로 받는** 모양으로 만든다.

```js
window.ISLAND = {
  id, title, theme,                 // 색·글꼴·배경
  world:   { terrain, props, zones },   // 지형·소품·구역
  cast:    [ {id, name, look, home} ],  // NPC
  quests:  [ {id, npc, ask, steps, checks, hint, evidence, concept} ],
  labs:    { <labId>: LabModule },      // 실험 모듈
  gifts:   [...],
};
```

- 실험 모듈 공통 인터페이스를 정하고 문서화한다(`engine/ENGINE.md`). 전기 섬의 `IslandCircuit` 이 그 인터페이스의 **첫 구현체**가 되게 맞춘다.
  최소한 이 정도는 있어야 한다: `mount(host, ctx)` · `setPhase(p)` · `render(state)` · `read()`(기록칸에 넣을 값) · `check(state)`(증거 태그 판정) · `unmount()`.
- 엔진에 남을 것: 3D 월드·이동·구역 진입 · 대사/부탁 카드 · 공방 모달(Step 카드·기록칸·힌트) · 일지 · `state.evidence[quest]` 영구 저장 · 개념 확인 틀 · 저장/복원(sanitize) · IME · 오디오 · 편의 설정 · 축하 연출 · 전체화면 clamp · 방문 집계.
- **합격 기준(바이트 일치는 더 못 씀):** `build.py --island sparkle` 결과를 포트 7100~7199 로 띄워 아래를 전부 통과.
  1. 표지 → 입장 → 섬에서 이동·시점 회전
  2. 퀘스트 0 두리(스위치) → 4 해온(축제)까지 **다섯 개 모두 완료**
  3. 새로고침 후 진행·일지·증거 태그가 그대로 남아 있음
  4. 드래그로 부품 연결(고스트가 모달 위에 보임) · 슬라이더(전압·저항 10/20/30 Ω) 반응
  5. 개념 확인 2문항 · 선물 5종 · 축하 연출
  6. 콘솔 오류 0, 한글 입력칸 정상
- 1단계 산출물과의 **diff 를 사람이 읽을 수 있게** 남긴다(무엇을 왜 옮겼는지 줄 단위 설명).
