# 레몬 백작의 부탁 · lemon-island

산과 염기·중화 반응(고1 통합과학) 스토리형 3D 탐험 실험 게임. 「놀러오세요 전기의 숲」과 같은 엔진.

## 이야기 한 줄
지구에서 온 과학자(플레이어)가 레몬 백작의 부탁으로 Dr.에시드(산)·Dr.베이스(염기)의 조수가 되어, 경계 마을 아이들에게 번진 **중화병**의 원인을 실험으로 밝히고 치료·예방법을 마을에 전한다.

## 퀘스트 · 실험 모듈

| 퀘스트 | 장소 | 실험 모듈 |
|---|---|---|
| Q0 프롤로그 — 레몬의 부탁, 기운 잃은 레몬 아이 | 레몬 성 | — |
| Q1 산이란? — 조수 테스트 | 에시드 연구실 | A 지시약 · A' 산+Mg(H₂) |
| Q2 산의 정체 H⁺ — 전도성·이온 이동·이온화 모형·강산/약산 | 에시드 연구실 → 레몬 성 보고 | B 전도/이온 이동 · C 입자 조립 |
| Q3 염기와 중화병 — OH⁻·강염기/약염기·시료 검출 | 경계 마을 → 베이스 연구실 | A(학생이 실험법 선택) · B · C |
| Q4 혼합 실험 ★ — 색·입자·남는 이온 | 버블 해안 → 베이스 연구실 | **D 혼합·입자·남는 이온·pH** |
| Q5 치료와 예방 — 중화 반응식·pH·지시약 4종·미지 시료 | 레몬 성 → 경계 마을 | C(반응식) · D(치료 모드) · E 미지 시료 판별 |

## 과학 규칙(핵심)
- 혼합은 "같은 농도, 10 mL = 이온 1쌍". 물 = min(H⁺, OH⁻), 남는 쪽이 액성 결정.
- Na⁺·Cl⁻ 같은 구경꾼 이온은 반응 뒤에도 물속에 그대로.
- 강염기 NaOH·KOH·Ca(OH)₂, 약염기 암모니아수. 약산 아세트산.
- 기체는 H₂. "전기분해"가 아니라 "이온의 이동". 손가락 실험 없음.
- 치료 목표는 중성이 아니라 "레몬 종족에게 필요한 산성 범위".
