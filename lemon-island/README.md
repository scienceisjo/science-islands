# 레몬 백작의 부탁 · lemon-island

산과 염기·중화 반응(고1 통합과학) 스토리형 3D 탐험 실험 게임. 「놀러오세요 전기의 숲」과 같은 엔진.
배포: https://scienceisjo.github.io/science-islands/lemon-island/

## 이야기 한 줄
지구에서 온 손님(플레이어)이 **레몬 성**에서 레몬 백작의 부탁을 받고, Dr.에시드(산)·Dr.베이스(염기)의 조수가 되어 경계 마을 아이들에게 번진 **중화병**의 원인을 실험으로 밝히고 치료·예방법을 마을에 전한다. 에시드의 조수로서는 비눗방울 돌풍에 흩어진 실험 도구를 하나씩 찾아 건네며 실험한다. 레몬 왕국은 노란 톤, 버블 왕국 경계 마을은 보라 톤.

## 파일
- `shell.html` — 화면 뼈대(표지 그림은 SVG 코드), `theme.css` — 공용 CSS 위에 덮는 섬 색
- `model.js` — 주민·부탁·대사·기록 문항·**흩어진 도구 tools**·**화학 규칙**(지시약·혼합·치료·이온화 모형)·저장(`fetch` 칸 포함, v1 기록은 옮겨 옴)
- `place.js` — 3D 섬(레몬 성과 안뜰·연구실 둘·경계 마을·비눗방울 해안, 노란 잎 나무·비눗방울 나무, 흩어진 실험 도구), 인물은 도형으로 직접 만듦
- `labs.js` — 여섯 실험대(그림·조작·기록 칸·힌트·`say()` 과학자 말풍선), `concept.js` — 발견 확인(고르기·증거 고르기, 보기 순서는 문항마다 고정해 섞음)
- `game.js` — 진행(여러 줄 대사·실험대 곁 과학자 말풍선·기록·보고서·지도·축제·파일)
- `원본대조.md` — 겨울쌤 수업 PPT ①~⑥ 장면·대사·실험·학습 요소와 게임의 대응표(그대로/바꿈/더함/뺌)
- `index.html` — **빌드 결과(직접 고치지 않는다)**: 저장소 루트에서 `python build.py lemon-island`
- `source/` — **로컬 전용(git 제외)**: 원본 PPT 추출본·`스토리바이블.md`(설계 원천)·참고 이미지

## 과학 규칙(핵심)
- 혼합은 "같은 농도, 10 mL = 이온 1쌍". 물 = min(H⁺, OH⁻), 남는 쪽이 액성. 온도는 물이 생길수록 오른다.
- Na⁺·Cl⁻ 같은 구경꾼 이온은 반응 뒤에도 물속에 그대로.
- 강산 염산·황산·질산 / 약산 아세트산, 강염기 NaOH·KOH·Ca(OH)₂ / 약염기 암모니아수.
- 기체는 H₂. "전기분해"가 아니라 "이온의 이동". 손가락 실험 없음. 온도는 온도계로.
- 치료 목표는 중성이 아니라 "레몬 종족에게 알맞은 산성 범위(pH 2.5~3.5)".
